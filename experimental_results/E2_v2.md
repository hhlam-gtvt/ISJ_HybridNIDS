## E2: RF Adaptation & Calibration

## Executive Summary

E2 v2.1 evaluates RF-21 using a strict Train/Calibration/Test protocol. Models trained on DEV_TRAIN (10 sessions); calibrators fitted and thresholds selected on DEV_CAL (5 sessions); Test evaluated as retrospective frozen re-evaluation.

- V1 Source: Score-order inversion; Test AUC 0.023 (direct) / 0.977 (inverted)

- V2a/V2b Calibration (fit on DEV_CAL): Scores collapse to base rate; BalAcc=0.50

- V3 seed=42: CAL BalAcc=1.00; Test AUC=0.9997 but Spec=0%, BalAcc=0.50

- V4 no-TTL: Same canonical binary decisions as V3, but multi-seed ranking less stable (AUC 0.817–1.000)

- Multi-seed: V3 AUC 0.9997±0.0000; V4 0.963±0.073 (one outlier seed=2026)

- Boundary: DEV_TRAIN=model fitting, DEV_CAL=calibration+threshold, TEST=evaluation only

## 2.4 Score-Order Inversion

The source model assigns higher direct attack scores to E1 normal flows than to attack flows. After inversion, ROC-AUC = 0.9993 (Dev) / 0.9767 (Test).

## 2.5 Calibration (V2a/V2b, fit on DEV_CAL)

Platt scaling and isotonic regression fitted on DEV_CAL did not recover a stable operating probability scale. Calibrated scores collapsed toward the calibration-set prevalence.


## 3. Conclusions

The source RF-21 exhibited score-order inversion on E1 (AUC 0.977 with inverted score on Test). Calibration on DEV_CAL did not produce a useful operating point. Local retraining restored ranking (Test AUC 0.9997, stable across 5 seeds) but the DEV_CAL-selected threshold yielded 0% specificity and chance-level balanced accuracy on Test, consistent with the substantial temporal-feature drift observed between Development and Test normal sessions.

V4 (no ct_state_ttl) produced the same canonical binary decisions as V3, but multi-seed ranking was less stable, including one seed with Test AUC = 0.817.

These findings provide the empirical basis to evaluate in E3 whether Suricata + RF evidence-aware routing can improve detection effectiveness.
